# Shashank Papnai — Portfolio

A responsive, light-theme personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP (if using the archive).
2. Open `index.html` in a browser.

No build step or package installation is required. Google Fonts are loaded online; system fallbacks are provided.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, scroll reveal and reading progress
